⚙️ Gestionar catálogo de productos

El Precio Base es el costo interno (parte en $0 — cárgalo tú, o impórtalo). El precio que ve el cliente siempre se calcula como Precio Base × (1 + % de recargo), y el % se define al armar cada cotización, no aquí.
Este catálogo se guarda solo en este navegador (no hay servidor). Si trabajas desde otro computador, usa "Exportar catálogo" aquí e "Importar catálogo" allá para mantenerlos iguales.
